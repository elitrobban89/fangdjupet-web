Fångdjupet är ett textbaserat rollspel i Java som vi byggde i grupp (tre personer) i kursen Javaprogrammering på ITHS. Hjälten tar sig igenom skolan rum för rum – Skoldörren, Kafferummet, Korridoren och Lektionssalen – och möter till sist Kapten Martin.

Spelet nedan är det riktiga Java-programmet: det körs på en server och du spelar det genom en terminal i webbläsaren. Välj med siffror, eller klicka på knapparna under terminalen.

  • Java 27
  • Strategy
  • Factory
  • Observer
  • JUnit – 298 tester
  • GitHub Actions
